01 / REPLACE & BUILD

Keep your existing repository

Replace the source files in your existing runpod-comfy-stateless repository using GitHub Desktop or the browser-only upload kit. No Terminal or CLI is required. Run Validate repository, then Build HQ workspace in GitHub Actions. Use the actual image digest reported by the successful build.

02 / CONFIGURE RUNPOD

Copy the selected settings

Create the comfy_password secret once. Use your existing hf_token and civit_token. Leave the container start command blank. Expose HTTP port 8188 only.

03 / WORK BY TASK

Open Workbench in ComfyUI

Log in as workbench using your password secret. The sidebar shows tasks, missing models and missing nodes. Prepare optional assets there without editing environment variables or rebuilding the image.
